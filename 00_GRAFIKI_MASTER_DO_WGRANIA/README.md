# 00_GRAFIKI_MASTER_DO_WGRANIA

Ten folder jest przeznaczony wyłącznie na sztywne, zatwierdzone grafiki MASTER 1:1, które mają być podpinane do CRM Pelet 1.3 PREMIUM bez zmiany wyglądu.

Zasady:
- użytkownik wgrywa tutaj gotową grafikę MASTER;
- grafika pozostaje wizualnie niezmieniona 1:1;
- logika, hotspoty i dane LIVE są podłączane pod grafiką;
- jedna karta = jedna poprawka = test = zamrożenie MASTER;
- nie używać tego folderu do plików tymczasowych, szkiców ani eksperymentów.

Pierwszy cel: karta DANE FIRMY.
